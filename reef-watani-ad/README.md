# إعلان موشن جرافيك — مشتل «ريف وطني»

إعلان رأسي 9:16 (1080×1920، 30 إطار/ث) لمدة 35 ثانية لتيك توك وريلز، مبني بـ [Remotion](https://remotion.dev).

## تسلسل المشاهد

| الوقت | اللقطات | النص على الشاشة |
|---|---|---|
| 0–5 ث | شتلة صغيرة قريبة + الشعار | من الجذور تبدأ الحكاية |
| 5–13 ث | صفوف الشتلات (3 لقطات) | أشجار برية وأشجار زينة |
| 13–23 ث | تنوع الأحجام (شاشة مقسومة لثلاث لقطات ثم لقطة واسعة) | خيارات تناسب الأفراد والمشاريع |
| 23–30 ث | فحص الشتلات وتجهيزها للتوريد | إنتاج وتوريد من ريف وطني |
| 30–35 ث | الشعار بوضوح على خلفية بيج | ريف وطني… ننمو مع أرضنا |

الألوان: أخضر داكن `#16311F` · ليموني `#C6DA5A` · بيج `#EFE5D0`. الخطوط: El Messiri للعناوين وTajawal للنصوص.

## إضافة المواد الحقيقية

كل المواد تُربط من ملف واحد: `src/assets.ts`.

1. **الشعار:** ضع الملف في `public/brand/logo.png` (يُفضَّل PNG بخلفية شفافة)، ثم اكتب `LOGO = 'brand/logo.png'`.
   إلى أن يُضاف يظهر شعار نصي مؤقت.
2. **اللقطات:** ضع مقاطع الفيديو في `public/footage/` (يُفضَّل رأسي 1080×1920، أو أفقي وسيُقصّ تلقائيًا)،
   ثم اكتب اسم كل ملف مكان `null` في `CLIPS`. كل خانة فارغة تعرض في المعاينة وصف اللقطة المطلوبة.
   يمكن تحديد ثانية البداية داخل المقطع بـ `startFrom`.
3. **التعليق الصوتي:** سجّل النص أدناه بصوت رجل سعودي، واحفظه في `public/audio/voiceover.mp3`،
   ثم اكتب `voiceover: 'audio/voiceover.mp3'`. يبدأ عند 0.6 ث، وتنخفض الموسيقى تلقائيًا تحته.

### نص التعليق الصوتي (نبرة دافئة وواثقة، سرعة متوسطة، ~30 ث)

> كل شتلة تبدأ بخطوة… وتكبر معها فرص جديدة.
> في ريف وطني، ننتج ونورّد شتلات الأشجار البرية وأشجار الزينة،
> بخيارات متنوعة تناسب الأفراد والمشاريع.
> من بداية النمو حتى تجهيز الطلب، نهتم بالتفاصيل التي تصنع الفرق.
> ريف وطني… ننمو مع أرضنا.

## الصوت

`scripts/make_audio.py` يولّد موسيقى هادئة (`music.wav`) ومؤثرات طبيعية خفيفة من رياح وأوراق وتغريد طيور (`ambience.wav`).
يمكن استبدالهما بأي موسيقى مرخّصة بنفس الاسم.

## التشغيل

```bash
npm install
npm run audio          # يعيد توليد الموسيقى والمؤثرات (اختياري)
npm run studio         # معاينة وتعديل تفاعلي
npm run render         # تصدير out/reef-watani-ad.mp4
```
